01

States and delay embedding

Suppose we measure a system at regular intervals, obtaining a time series x = (x1, …, xN). A single observation may give an incomplete description of its state. A pendulum, for example, passes through the same position while moving in either direction.

Delay embedding forms a state vector from several observations separated by a fixed number of samples:

si = (xi, xi+τ, …, xi+(m−1)τ)
Embedding dimension m
The number of coordinates in each vector.
Time delay τ
The separation between successive coordinates, in samples.

For m = 2 and τ = 1, each vector contains two consecutive values: (xi, xi+1). For τ = 2, it contains (xi, xi+2).

The final coordinate must stay within the recorded series. The number of available state vectors is therefore N′ = N − (m − 1)τ.

02

The recurrence matrix

A recurrence plot compares all pairs of state vectors. A pair is recurrent when its distance d is no larger than the threshold ε:

Rij =
1 if d(si, sj) ≤ ε0 otherwise

Displaying the entries equal to 1 as dark points gives the recurrence plot. With N′ state vectors, both the matrix and the RP have size N′ × N′.

Axis convention. Both axes show the time indices of the state vectors. Column j and row i locate the comparison of states sj and si. Time increases rightwards and upwards; the identity line runs from bottom left to top right.

03

The recurrence threshold

Measured states rarely repeat exactly. A nonzero threshold includes states that are sufficiently close. The recurrence rate (RR) is the percentage of matrix entries equal to 1:

RR = 100 × (number of recurrent pairs) / (N′)²

Here RR includes the identity line. Changing ε changes the number of accepted pairs. The following exercise uses xt = sin(0.1πt), with t = 0, …, 119, m = 3 and τ = 5. The period is 20 samples.

Solution and observations

Every pair accepted at a smaller threshold is also accepted at a larger one. RR therefore increases or stays constant. With this embedding, ε = 0.05 and ε = 0.20 accept the same pairs; ε = 0.80 adds recurrences. The bands generally become wider as ε increases. At very large ε, the plot loses detail as most states are treated as recurrent.

At exactly ε = 0, floating-point rounding can make theoretical repetitions of the sine wave slightly unequal. The useful threshold range also depends on scaling, distance measure and embedding.

04

Embedding parameters

For a sine wave, the same amplitude occurs on the rising and falling parts of a cycle. Delayed coordinates help distinguish these states. A delay of five samples corresponds to a quarter of the period in this example; a delay of one sample gives more strongly related coordinates.

05

Interpreting RP structures

Diagonals parallel to the identity line occur when two segments of a trajectory remain close over successive time steps. Vertical and horizontal runs can occur when the system stays near a state for a while. Isolated points record individual recurrences without a longer sequence of similar evolution.

06

β-divergence

For positive values a and b, the β-divergence is defined by

dβ(a, b) =aβ + (β − 1)bβ − βabβ−1β(β − 1)β ≠ 0, 1.

The cases β = 0, 1 and 2 are:

Special cases
βdβ(a, b)Case
0a/b − ln(a/b) − 1Itakura–Saito
1a ln(a/b) − a + bGeneralized Kullback–Leibler
2½(a − b)2Half squared Euclidean distance

Here ln is the natural logarithm. For state vectors, sum these contributions over corresponding coordinates to obtain Dβ(si, sj). The order matters: the divergence is generally asymmetric.

Homogeneity and amplitude

Scaling both arguments by the same positive factor c gives

dβ(ca, cb) = cβ dβ(a, b),  c > 0.

The same property holds for state vectors. For a fixed relative difference, positive β gives greater weight to larger amplitudes, while negative β gives greater weight to smaller amplitudes. At β = 0, the divergence is unchanged by scaling.

Definition and homogeneity: Févotte & Idier (2011), §2.1.
